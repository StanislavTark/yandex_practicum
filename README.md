# Проекты по анализу данных — Яндекс Практикум

11 учебных проектов, выполненных и защищённых в рамках обучения в Яндекс Практикуме: исследовательский анализ, статистика и A/B-тесты, продуктовые метрики и юнит-экономика, SQL, дашборды в Tableau.

Каждый проект лежит в своей папке: ноутбук `.ipynb` с решением и README с описанием задачи, данных и выводов. Если ноутбук не отображается на GitHub, его можно открыть через [nbviewer](https://nbviewer.org/github/StanislavTark/yandex_practicum/tree/main/).

**Стек:** `Python` `pandas` `NumPy` `SciPy` `Matplotlib` `Seaborn` `Plotly` `SQL / PostgreSQL` `Tableau`
